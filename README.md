isi file dan deskripsi program yakni:
1. sistem_nilai.cpp (soal 1): data mahasiswa dalam single linked list, lalu nilai dalam dynamic array (vector). fiturnya ada insertion sort, cari NIM (liniear search), cari nilai (Binary search)
2. antrean.cpp (soal 2): queue untuk antrean minjam, stack untuk riwayat pengembalian, binary search tree untuk id buku. fiturnya ada cari ID lalu traversal
3. rute.cpp (soal 3): graph dengan adjacency matrix berbobot. Fitur BFS, DFS, dijkstra
4. hash.cpp (soal 4): hash dimana table ukuran 20 dengan nim sebagai key, nama sebagai value. Collision di tangani dengan Doube hashing. Fitur : insert, search, remove, display
